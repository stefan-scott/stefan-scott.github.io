# Creature Creator

**Points:** 10.0
**Submission type:** online upload

Create a function drawCreature(turtle, numberOfLegs) which makes a turtle draw a creature with a specific number of legs. For example, if drawCreature(francis, 4) is called, the creature should be drawn with 4 legs. If drawCreature(francis, 7) is called, the creature should be drawn with 7 legs. Ensure that the following is met in your program:

1. **Pass a Turtle**  
     
   For this assignment, you need to define a turtle outside of your function, then pass that turtle instance to the function as an argument (like drawCreature(**francis**,4) above).
2. **Scalable**  
     
   Your creature should be able to handle a large variety of arguments for the number of legs. Consider how changing the number of legs will impact the rest of the creature (size/shape of body, etc...) *There are many ways to accomplish this - be creative!*
3. **Docstring**A Docstring is a special piece of internal documentation that typically is included in every function, which describes the purpose of that function. In this assignment, you must include a properly formatted Docstring for your drawCreature() function. See the style guide for [Docstrings here.](https://www.python.org/dev/peps/pep-0257/)

**Extra for Experts**

Use the [Python Docs turtle reference](https://docs.python.org/2/library/turtle.html) to do the following:

- make something interesting happen when the mouse is clicked
- make and fill a polygon and use it as part of your creature
