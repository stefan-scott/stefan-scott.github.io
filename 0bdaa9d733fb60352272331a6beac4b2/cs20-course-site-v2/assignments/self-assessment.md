# Self Assessment

**Points:** 5.0
**Submission type:** online upload
**Allowed file types:** doc,docx

Now that you've completed your Scratch Major Project, please take a moment to reflect on the work you put into this project. Download the following self-assessment rubric: [Self Assessment](../files/web_resources/Scratch-Project-Self-Assessment.docx "Scratch Project Self-Assessment.docx")

Thoughtfully fill out this rubric, by highlighting one box in each row. If you want to select an 'in-between' value (such as in between Exceptional and Proficient, then highlight both boxes in that row).

Once complete, submit your rubric here. The mark will be represented on canvas as a grade out of 5.
