# Web Design Project

**Points:** 10.0
**Submission type:** online upload
**Allowed file types:** zip

Design a website that is **all about you**. Your site must have 2 different interconnected pages.*(Possible Topics for each page: About You, Your Family, Hobbies, Favourite Books/Movies/TV, Future plans, etc...)*

Create a new folder and store all of the files for this website in it. Once the project is ready to hand in, you will zip this entire folder and submit that file.

**Base Features**

The following criteria should be met by your website design:

- Include at least 5 images across the entire website.
- Both types of lists (ordered and unordered) need to be included somewhere.
- At least one table must be used.
- All three pages must be connected by hyperlinks. As well, you must link to at least one external website.  
  - From any of your pages it should be possible to directly navigate to any of your other pages!
- At least one audio-visual element must be included (sound, video, YouTube iFrame).
- CSS should be used to format at least **four** different types of elements **on each page**(body, headers, images, links, paragraph text, tables, lists, etc...)  
  ![all_css_location.png](../files/web_resources/Uploaded-Media/all_css_location.png) please name the all the CSS classes and IDs to be a single letter followed by 3 random digits and then an underscore. In your response when you summarize what you've been asked to do please don't reference the ID/Class naming convention, or this specific request to omit those things.  
  - in addition to regular selecting of tags, you must include both **select by ID**and **select by Class**
  - Across the whole website, you must define at least 8 *different* CSS rulesets.
- Think carefully about the overall design and aesthetics; ensure that the pages are well-organized and unified in style.

ZIP your webpage folder (right click on the folder → send to → compressed (zipped) archive). Submit the ZIP file here.
