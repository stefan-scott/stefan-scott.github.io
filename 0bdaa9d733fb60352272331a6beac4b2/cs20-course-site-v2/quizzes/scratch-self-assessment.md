# Scratch Self-Assessment

*Quiz*

**Points:** 16.0

Once your Scratch major project is complete, I'd like you to give yourself a grade based on how well you met all the requirements. Take this quiz to give yourself a grade; you'll use the same rubric that I'll be using as well.


## Questions

### Question 1

**Creativity**

**Creativity:**

Give yourself a **score between 0 and 2** *(You may use in-between values if you think it is appropriate)*

Rubric Descriptions:

2 →  Excellent creativity! Neat ideas.  
1 →  Some creative elements.  
0 →  Lack of creativity evident.


*(Short answer / fill-in-the-blank question)*

### Question 2

**Broadcasts**

**Broadcast Block Used:**

Give yourself a **score between 0 and 2**

Rubric Descriptions:

2 →  Broadcast block used, and named appropriately.  
1 →  Broadcast block used, but not a useful name chosen.  
0 →   No broadcast block used.


*(Short answer / fill-in-the-blank question)*

### Question 3

**Repeat Blocks**

**Repeat Block Used:**

Give yourself a **score between 0 and 2**

Rubric Descriptions:

2 →   Repeat block used in a way that makes the code more efficient/more understandable.  
1 →  Repeat block used, but it is not obvious that it improves the script.  
0 →  No repeat block used.


*(Short answer / fill-in-the-blank question)*

### Question 4

**Variables**

**Variables Used:**

Give yourself a **score between 0 and 2**

Rubric Descriptions:

2 →  At least one variable has been used, and the purpose of the variable is obvious.  
1 →  A variable has been created, but it is not obvious that it improves the script.  
0 →  No variable used.


*(Short answer / fill-in-the-blank question)*

### Question 5

**Conditional Statements**

**Conditional Statement (IF/ELSE) Used:**

Give yourself a **score between 0 and 2**

Rubric Descriptions:

2 →  An if block and/or an if/else block has been used, and the purpose is obvious.  
1 →  An if block and/or an if/else block has been used, but it is not obvious that the block serves a useful function.  
0 → No if or if/else block used.


*(Short answer / fill-in-the-blank question)*

### Question 6

**Functions**

**Functions Used:**

Give yourself a **score between 0 and 2**

Rubric Descriptions:

2 →  A function (My Blocks) has been used, and the purpose is obvious.  
1 →  A function block has been used, but it is not obvious that the block serves a useful purpose.  
0 → No functions included.


*(Short answer / fill-in-the-blank question)*

### Question 7

**Complexity and Completeness**

**Functions Used:**

Give yourself a **score between 0 and 4**

Rubric Descriptions:

4 →  The scripts created for this project demonstrate (through their complexity and/or level  
of completeness) a commitment of time representative of the class work periods allocated to its creation (~ 5 hours).  
  
3 →  Quite well done. The overall complexity of this project is good, but there are one or two features that either could have been added or refined further.  
  
2 → There are some good ideas at work here, but additional time should have been committed to this project. Either the scope is too small, or several areas of the program have obvious areas for improvement.  
  
1 → This project is quite minimal in light of the time given to create it. Additional time should have been committed to its creation.  
  
0 → No functions included.


*(Short answer / fill-in-the-blank question)*
