# Canadian Computing Challenge Question J1

Each year, the University of Waterloo puts on the **Canadian Computing Competition.** This is an optional challenge students can take on to push their abilities further. Below is a question from a previous year's competition that I'd like you to try. This is a *Level 1* (of 5) question.

Problem is [here.](../files/web_resources/Uploaded-Media/CCC-Junior_1.pdf "CCC-Junior_1.pdf")

**Taking Input:**

Your program should begin by taking input from the user 4 times (and storing the results of each input). Once that is done, some logic should determine what result to output (either answer or ignore) to the shell.

**Test Cases:**

Try your program out with the following inputs to verify correctness:

7 2 2 4 → IGNORE  
8 1 2 3 → IGNORE  
4 5 6 7 → ANSWER  
1 1 2 2 → ANSWER
