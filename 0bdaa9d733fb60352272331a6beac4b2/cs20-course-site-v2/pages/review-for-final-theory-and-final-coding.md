# Review for Final Theory and Final Coding

The class will conclude with two major assessments:

- Theory Final  -  A larger quiz, focusing on theory topics and code comprehension.
- Coding Final - A practical coding assessment: **1 Reeborg world** to solve  and  **1 Python program** to create

To study for these assessments, the following are recommended:

**Theory Final Preparation:**

- Practice Quizzes on Canvas can be attempted again
- [www.cs20.ca](http://www.cs20.ca)  has a section titled Python Practice Quizzes
- [www.cs20.ca](http://www.cs20.ca)  has a section titled End of Semester Review

**Coding Final Preparation:**

- [www.cs20.ca](http://www.cs20.ca)  has a section titled End of Semester Review
- Work through some Python Coding Bats exercises . Suggestions to try:
  - [warmup-1: front\_back](https://codingbat.com/prob/p153599)
  - [warmup-1: near\_hundred](https://codingbat.com/prob/p124676)
  - [warmup-2: front\_times](https://codingbat.com/prob/p124676)
