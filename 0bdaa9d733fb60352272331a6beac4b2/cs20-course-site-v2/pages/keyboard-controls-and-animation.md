# Keyboard Controls and Animation

Often we will want to give users different mechanisms for interacting with our software. One common way is to register an event when a button on the keyboard is pressed. We would use the "When \_\_\_\_ key is pressed" block:

![keypress.jpg](../files/web_resources/keypress.jpg)

As a class, we will discuss techniques for animating sprites. In Scratch, this involves using multiple *costumes* and cycling through them to create the illusion of movement.

Download the following ZIP of images to use: [Gorilla Images](../files/web_resources/Gorilla-Sprites.zip "Gorilla Sprites.zip")

Class Activity:

Using the sprites you ripped from the image above as well as those already ripped into the ZIP file above, you have enough images for four separate actions:

1. An idle movement
2. Running
3. Chest Pound
4. Arm Swing

Making one of these actions appear is fairly simple, but once we add the costumes for all four actions it becomes evident that we need to add some logic to have our program correctly decide which costumes to display.

By the end of class, we should be able to have our gorilla play the **idle animation** when no keys are being pressed. If the user presses left or right, the gorilla should use the **running action**, and move in the correct direction. When the user presses the up arrow, the **chest pound** should be shown, and the space bar should activate the **arm swing.**
