# Overview of Review Topics

## Scratch

- Make a script that can do the class activity ([Experiment with Repeat](#unresolved-experiment-with-repeat "Class Activity: Experiment With Repeat")), but can draw any of the shapes. Bind the Up Arrow key to adding more sides to the regular polygon, and bind the Down Arrow key to decreasing the number of sides. You should restrict the up and down arrow keys to keeping the value of the number of sides between 3 and 12. Space bar should draw the shape. Add a key to clear the screen. Experts can try the star.
- Keep track of variables in a loop. Work through the class activity ([Repeat Until](#unresolved-repeat-until "Class Activity: Repeat Until")).
